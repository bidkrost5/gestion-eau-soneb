Comment installer l'application sur votre téléphone Android ou iPhone ?

Android (Google Chrome)

  1. Ouvrez le lien de cette page dans Chrome.
  2. Appuyez sur le menu (les 3 points en haut à droite).
  3. Sélectionnez « Installer l'application » ou « Ajouter à l'écran d'accueil ».

iPhone / iPad (Safari)

  1. Ouvrez le lien dans le navigateur Safari.
  2. Appuyez sur le bouton Partager (carré avec une flèche vers le haut).
  3. Déroulez puis choisissez « Sur l'écran d'accueil ».
